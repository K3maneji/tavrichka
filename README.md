# Tavrichka — GitHub Pages + Google Apps Script + Google Sheets

## Архитектура
- GitHub Pages: статические HTML/CSS/JS-файлы.
- Google Sheets: закрытая таблица с данными журнала.
- Google Apps Script: API, который проверяет ID и отдаёт оценки найденного ученика.
- Отдельный сервер и Google API Key не требуются.

## ВАЖНО О ДОСТУПЕ ПО ОДНОМУ ID
Вход только по ID — это не полноценная защита паролем. Любой человек, который знает или угадает ID другого ученика, потенциально сможет увидеть его оценки. Используйте такой режим только если это осознанно согласовано с администрацией и учениками. Для персональных учебных данных безопаснее использовать дополнительный фактор авторизации.

## 1. Подготовить Google Таблицу
1. Загрузите `Журнал КСК31.xlsx` в Google Drive.
2. Откройте его через Google Таблицы и преобразуйте в формат Google Таблиц.
3. Проверьте, что в первой строке каждого листа есть колонка `ID ученика` и, желательно, `ФИО ученика`.
4. Не публикуйте таблицу и не включайте доступ «Все, у кого есть ссылка».

## 2. Установить Google Apps Script
1. Откройте именно эту Google Таблицу.
2. Выберите **Расширения → Apps Script**.
3. В файле `Code.gs` замените код содержимым `gas/Code.gs` из этого проекта.
4. Сохраните проект.
5. **Не запускайте `setupAccessCodes`: в этой версии такой функции нет, PIN-коды не используются.**
6. Откройте **Развернуть → Управление развертываниями** и отредактируйте веб-приложение либо создайте новое.
7. Тип: **Веб-приложение**; выполнять от имени: **Меня**; доступ: **Все** (название настройки может отличаться).
8. Разверните новую версию и скопируйте URL `/exec`.

## 3. Подключить Apps Script к сайту
1. Откройте `js/api.js`.
2. Укажите URL веб-приложения `/exec` в `window.TAVRICHKA_API_URL`.
3. В этой сборке уже указан URL, который пользователь ранее прислал в переписке. Если после обновления Apps Script URL изменился, замените его на новый.

## 4. Опубликовать на GitHub Pages
1. Загрузите содержимое проекта в корень GitHub-репозитория, чтобы `index.html` был в корне.
2. Откройте **Settings → Pages**.
3. Выберите публикацию из ветки `main`, папка `/ (root)`.
4. Сохраните и дождитесь публикации.

## 5. Проверка
- Введите существующий ID ученика.
- Проверьте ФИО и доступные разделы.
- Проверьте оценки на каждом листе.
- Убедитесь, что `н` и другие буквенные обозначения отображаются, но не участвуют в среднем балле.
- При истечении сессии войдите повторно.

## Обновление данных
Изменения в Google Таблице отображаются при следующем запросе; GitHub Pages повторно публиковать не нужно. Добавленные видимые листы автоматически появятся в списке разделов.

## Обновление Apps Script
После изменения `Code.gs` сохраните проект и обновите существующее развертывание через **Развернуть → Управление развертываниями → Изменить → Новая версия**.

## Структура
- `index.html`, `grades.html` — страницы сайта.
- `css/` — стили.
- `js/api.js` — URL Apps Script и клиент API.
- `js/script2.js` — вход по ID.
- `js/script.js` — отображение оценок.
- `gas/Code.gs` — серверная логика Apps Script.
- `gas/appsscript.json` — манифест.
