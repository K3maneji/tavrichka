# Таврический колледж — GitHub Pages + Google Apps Script + Google Sheets

## Архитектура
- GitHub Pages: только статические HTML/CSS/JS-файлы.
- Google Sheets: исходные данные журнала.
- Google Apps Script: проверка доступа и выдача данных только вошедшему ученику.
- Отдельный сервер/VDS не нужен.

## 1. Подготовить Google Таблицу
1. Откройте Google Drive.
2. Загрузите `Журнал КСК31.xlsx`.
3. Откройте файл через Google Таблицы и выберите **Файл → Сохранить как Google Таблицы** (если Drive не конвертировал его автоматически).
4. Проверьте, что все 12 листов перенесены, а в первой строке каждого листа есть колонки `ФИО ученика` и `ID ученика`.
5. Не публикуйте таблицу в интернете и не включайте доступ «Все, у кого есть ссылка».

## 2. Установить Google Apps Script
1. Откройте именно эту Google Таблицу.
2. Выберите **Расширения → Apps Script**.
3. Удалите демонстрационный код в `Code.gs` и вставьте содержимое `gas/Code.gs` из этого проекта.
4. В настройках проекта включите показ файла манифеста `appsscript.json` (если нужно) и замените его содержимое на файл `gas/appsscript.json`.
5. Сохраните проект.
6. В списке функций выберите `setupAccessCodes` и нажмите **Выполнить**.
7. Подтвердите разрешения Google.
8. Откройте **Журнал выполнения** и сохраните выведенный список ID/PIN. Передайте PIN-коды ученикам лично. Не публикуйте список и не отправляйте его в общий чат.
   - Функция создаст скрытый защищённый лист `_Доступ`.
   - Не удаляйте и не редактируйте этот лист.
   - Функцию `setupAccessCodes` нужно выполнить только один раз.
9. Нажмите **Развернуть → Новое развертывание**.
10. Тип: **Веб-приложение**.
11. Выполнять от имени: **Меня**.
12. У кого есть доступ: **Все** (если в интерфейсе Google доступен такой вариант; для публичного GitHub Pages иначе браузер не сможет обратиться к веб-приложению).
13. Нажмите «Развернуть», скопируйте URL веб-приложения, заканчивающийся на `/exec`.

> Таблица остаётся закрытой. Публичен только веб-адрес скрипта; данные выдаются после проверки ID + PIN. Не добавляйте PIN-коды в исходники или саму таблицу журнала.

## 3. Подключить Apps Script к сайту
1. Откройте `js/api.js`.
2. Найдите строку `window.TAVRICHKA_API_URL`.
3. Вместо `ВСТАВЬТЕ_URL_ВЕБ_ПРИЛОЖЕНИЯ_APPS_SCRIPT` вставьте скопированный URL `/exec`.
4. Сохраните файл.

## 4. Опубликовать на GitHub Pages
1. Загрузите содержимое папки проекта в GitHub-репозиторий (в корень, чтобы `index.html` был в корне).
2. Откройте **Settings → Pages**.
3. В разделе Build and deployment выберите публикацию из ветки `main` и папки `/ (root)`.
4. Сохраните и дождитесь публикации.
5. Откройте сайт по адресу GitHub Pages.

## 5. Проверка
- Войдите с ID и PIN одного ученика.
- Проверьте каждый из 12 листов.
- Убедитесь, что `н`, `н/а` и пустые ячейки отображаются как есть и не попадают в средний балл.
- Средний балл считается только по числовым оценкам от 1 до 5.
- При истечении сессии сайт вернёт пользователя на страницу входа.

## Обновление таблицы
Меняйте оценки в Google Таблице. Сайт читает актуальные значения при каждом запросе — повторно публиковать GitHub Pages не нужно. Если добавляете новый лист, он автоматически появится в списке разделов, если он не скрыт и не называется `_Доступ`.

## Безопасность и ограничения
- PIN-коды генерируются индивидуально и хранятся в скрытом системном листе только в виде SHA-256-хэша с солью.
- После успешного входа создаётся временная сессия на 6 часов.
- После 5 неверных попыток для одного ID вход временно блокируется на 10 минут.
- Google Apps Script имеет квоты и ограничения по времени выполнения; для небольшого электронного журнала этого обычно достаточно, но это не замена полноценной системе с корпоративной авторизацией.
- Для изменения кода Apps Script после публикации создайте новое развертывание или обновите существующее через **Развернуть → Управление развертываниями → Изменить → Новая версия**.
- Не храните PIN-коды в GitHub. Не делайте репозиторий с исходными персональными данными публичным.

## Структура
- `index.html`, `grades.html` — страницы сайта.
- `css/` — исходные стили (дизайн сохранён).
- `js/api.js` — адрес Apps Script и JSONP-клиент.
- `js/script2.js` — вход.
- `js/script.js` — отображение оценок.
- `gas/Code.gs` — серверная логика Google Apps Script.
- `gas/appsscript.json` — манифест Apps Script.
